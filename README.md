# SaaS CRUD de Clientes

Projeto estilo sistema interno/SaaS com cadastro de clientes, planos, status, indicadores e exclusão.

## Tecnologias
- React
- Vite
- LocalStorage
- Componentização
- Responsividade

## Como rodar
```bash
npm install
npm run dev
```

## Como subir no GitHub
```bash
git init
git add .
git commit -m "feat: projeto saas crud de clientes"
git branch -M main
git remote add origin URL_DO_SEU_REPOSITORIO
git push -u origin main
```

## Deploy sugerido
Vercel ou Netlify.
